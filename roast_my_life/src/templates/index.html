Welcome to Your AI Language Learning Assistant 🎉

This interactive application uses the Reka Vision API to help you learn languages through video content. Watch videos and chat with an AI tutor that understands what you're watching.

Select a video, ask questions about phrases, grammar, or cultural context, and get instant explanations with English translations. Perfect for visual learners!

Features

  • 🎥 Video-based learning with auto-play and timestamp jumping
  • 💬 AI-powered chat that understands video context
  • 🌐 Automatic English translations for foreign phrases
  • 🧠 Grammar explanations and cultural context
  • 📱 Responsive design that works on all devices

How It Works

Head over to Select Video, pick a video, and click 💬 Start Learning. The video plays automatically while you chat with an AI tutor about what you're watching.

Tip: Ask specific questions about phrases, grammar, or cultural context for the best learning experience!
